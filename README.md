# Ismail Guennouni — Intelligence in interaction

Personal academic website: https://ismailg.github.io/

Research on cooperation, social cognition, computational psychiatry, and interaction among humans and artificial agents.

## Editing

- `index.html`: biography, research themes, publications, and education.
- `style.css`: appearance and responsive layout.
- `script.js`: publication filters, search, navigation, and the email reveal button.
- `publications.json`: structured publication records; keep these consistent with the page.
- `robots.txt` and `sitemap.xml`: search-engine discovery.

GitHub Pages publishes the root of the `main` branch. No build step or external service is required. The `.nojekyll` file preserves the static files as written.

The email button reveals the professional address on demand. This discourages simple harvesting but does not prevent determined bots from finding it.
